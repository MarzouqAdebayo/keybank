## CONTRIBUTING.md

```markdown
# Contributing to keybank

Thanks for considering contributing! Please review these steps:

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Follow Go code style: `go fmt`, `go vet`, `golangci-lint run`
4. Write tests for new functionality.
5. Commit with a clear message and push to your fork.
6. Open a Pull Request and link relevant issue.

## Issue Guidelines

- Check existing issues before filing a new one.
- Provide steps to reproduce and expected behavior.

## Code Style

- Follow [Effective Go](https://golang.org/doc/effective_go).
```
